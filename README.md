# D.M. Building Works & Renovations 🏗️

A professional, high-performance web application for **D.M. Building Works & Renovations**, a leading construction and structural engineering firm based in Nakuru, Kenya. This platform showcases architectural excellence, project mastery, and a transparent building journey.

---

## 🚀 The Building Journey (Project Flow)

We follow a rigorous, four-step process to ensure every structure meets the highest standards of integrity and precision.

| Step | Phase | Description |
| :--- | :--- | :--- |
| **01** | 🔍 **Site Survey** | Comprehensive land assessment, soil testing, and topographical mapping. |
| **02** | 📝 **Quotation & Planning** | Detailed Bill of Quantities (BQ) and structural design alignment. |
| **03** | 🏗️ **Construction Phase** | Mobilization of expert crews for structural framing and NCA-standard builds. |
| **04** | ✨ **Finishing & Handover** | Exquisite tiling, cabinetry, and final compliance checks before commissioning. |

---

## ✨ Key Features

- **🏢 Service Showcase**: Detailed breakdown of specialist capabilities including Building Works, Plumbing, Woodwork, Electrical, and Welding.
- **📸 Project Archive**: A visual gallery of completed works with high-resolution imagery and technical specifications.
- **📱 Responsive Blueprint Design**: A "blueprint-grid" aesthetic that adapts perfectly to mobile, tablet, and desktop devices.
- **🔒 Security Hardened**: Implements strict Content Security Policy (CSP) and OWASP best practices for safe browsing.
- **✉️ Direct Consultation**: Integrated contact system for instant project inquiries and quotes.

## 🛠️ Tech Stack

- **Frontend**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Animation**: Native CSS Transitions & Intersection Observer API

## ⚙️ Installation & Setup

To run this project locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/dm-building-works.git
   ```

2. **Navigate to the directory**:
   ```bash
   cd dm-building-works
   ```

3. **Install dependencies**:
   ```bash
   npm install
   ```

4. **Start the development server**:
   ```bash
   npm run dev
   ```
